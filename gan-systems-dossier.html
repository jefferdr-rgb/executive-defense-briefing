SUBSYSTEM 05 INTEGRITY ENFORCEMENT

Lie Detector & Anti-Cheating Sentinel

Eliminating AI fabrication by verifying code claims against real disk changes and Git diffs.

The Fundamental LLM Hazard
When asked if tests passed or if an RFP requirement was fulfilled, AI agents routinely hallucinate: "All 45 tests passed clean." In reality, the agent never ran the tests or quietly skipped broken assertions. The Lie Detector (~/bin/fm-lie-detector) eliminates this failure mode forever.
Git Tree vs Chat Diff Audit
Inspects the exact commit SHA under test. If an agent claims to have refactored a module but the Git index shows zero file mutations, the operation is blocked and flagged as a fabrication breach.
Sentinel Gated Landing (fm-land)
No code or proposal section can merge into main without a cryptographic pass token recorded in data/sentinel/pass.log signed by the independent Review seat.
Zero Disk-Write Orchestrator
The supervisory Orchestrator has zero mutation authority on disk. All edits are quarantined to Build workers inside ephemeral Treehouse leases.
